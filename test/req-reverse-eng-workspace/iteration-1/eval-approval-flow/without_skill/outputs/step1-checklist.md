# 请假审批流程 -- 需求澄清检查清单

> 原始需求："做一个请假审批流程，员工提交请假申请，直属领导审批，超过3天的需要部门经理二次审批。"

---

## 1. 请假申请基础字段

- [ ] 请假类型有哪些？（年假、事假、病假、婚假、产假、丧假、调休等）不同类型是否有不同的审批规则或额度限制？
- [ ] "天数"的计算方式：是自然日还是工作日？是否需要排除法定节假日和周末？
- [ ] 是否支持半天请假（如只请上午或下午）？最小请假粒度是什么？
- [ ] 请假申请需要附件吗？（如病假需要医院证明）哪些类型强制要求附件？
- [ ] 请假时间是否允许跨月、跨年？如果跨年，额度如何扣减？

## 2. "超过3天"的判定规则

- [ ] "超过3天"是指 >3 还是 >=3？即恰好3天是否需要部门经理审批？
- [ ] 该阈值是否因请假类型不同而不同？（如病假阈值可能更高）
- [ ] 阈值是否可配置，还是硬编码为3天？未来是否会根据部门或职级调整？
- [ ] 如果员工分多次提交短期请假以规避二次审批（拆单），系统是否需要检测和防范？

## 3. 组织架构与角色权限

- [ ] "直属领导"如何确定？是从组织架构树自动获取，还是手动指定？
- [ ] 如果员工没有直属领导（如新员工、组织架构未维护），流程如何处理？
- [ ] "部门经理"是一个固定角色标签，还是组织架构中的某个层级？
- [ ] 直属领导和部门经理是同一人的情况如何处理？（如小部门只有一级管理者）是否需要去重，只审批一次？
- [ ] 部门经理本人请假，谁来审批？是否需要向上递归到更高层级？
- [ ] 直属领导本人请假，其下属的请假申请在审批期间由谁代审？

## 4. 状态机与流转规则

- [ ] 完整的状态列表是什么？建议至少包含：草稿、待直属领导审批、待部门经理审批、已通过、已驳回、已撤回、已取消。
- [ ] 员工在"待审批"状态下能否撤回申请？撤回后是否可以重新提交？
- [ ] 审批人驳回后，员工是否可以修改后重新提交？重新提交后流程从哪一步开始？
- [ ] 直属领导通过后、部门经理尚未审批时，直属领导能否反悔撤回审批？
- [ ] 是否需要审批超时机制？如果审批人长时间不处理，是否自动提醒、自动转审或自动通过？
- [ ] 是否支持加签（审批人临时增加一个审批节点）或转审（审批人将审批权转给他人）？

## 5. 审批动作与结果

- [ ] 审批动作只有"通过"和"驳回"两种吗？是否需要"退回修改"（区别于驳回，允许重新编辑提交）？
- [ ] 驳回时是否必须填写驳回原因？
- [ ] 是否需要支持批量审批（审批人一次性处理多条申请）？
- [ ] 审批通过后是否需要自动同步到考勤系统、HR系统或日历？

## 6. 通知与消息

- [ ] 每个状态变更需要通知哪些人？通过什么渠道通知？（站内信、邮件、企业微信/钉钉、短信）
- [ ] 审批待办是否需要在首页或工作台以红点/数字提醒？
- [ ] 审批超时后是否需要催办通知？催办频率和上限是什么？

## 7. 并发与冲突场景

- [ ] 同一时间段内是否允许重复提交请假申请？系统是否需要做时间段冲突校验？
- [ ] 如果同一部门多人同时请假，是否有上限控制（如同一天请假人数不得超过团队的 N%）？
- [ ] 审批人和申请人同时操作（如员工撤回的同时审批人通过），如何处理并发冲突？

## 8. 假期额度与余额

- [ ] 是否需要在提交时校验剩余假期额度？额度不足时是否阻止提交？
- [ ] 审批通过后是否自动扣减额度？驳回或撤回后是否自动回补？
- [ ] 不同假期类型的额度规则分别是什么？（年假按工龄、事假无上限但扣薪等）

## 9. 数据查询与报表

- [ ] 员工需要看到哪些视图？（我的申请列表、审批历史、假期余额）
- [ ] 审批人需要看到哪些视图？（待我审批、我已审批、团队请假日历）
- [ ] HR 或管理层是否需要统计报表？（部门请假汇总、月度/年度统计）
- [ ] 审批记录需要保留多久？是否有合规性要求？

## 10. 非功能性需求

- [ ] 预期用户量和并发量级别？（影响技术选型和架构设计）
- [ ] 是否需要移动端支持？（APP / 企业微信小程序 / H5）
- [ ] 是否需要与现有 OA、HR、考勤系统对接？对接方式是什么？（API / 消息队列 / 数据库直连）
- [ ] 审批流程引擎是否有现成选型？（如 Activiti、Flowable、Camunda，或自研状态机）
- [ ] 是否需要审计日志？（记录每一步操作的操作人、时间、IP 等）

## 11. 边界与异常场景汇总

| 场景 | 需确认的处理方式 |
|------|------------------|
| 请假跨越节假日 | 是否自动扣除节假日天数 |
| 申请人离职或调岗 | 进行中的审批流如何处置 |
| 审批人离职或调岗 | 待审批的单据如何转交 |
| 组织架构变更 | 已发起的流程是否随之变更审批人 |
| 请假开始日期已过 | 是否允许补提请假申请 |
| 系统故障恢复后 | 审批流是否能从断点继续 |
