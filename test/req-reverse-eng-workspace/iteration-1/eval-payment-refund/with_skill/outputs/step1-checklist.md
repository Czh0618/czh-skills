# 防御性需求清单

**原始需求**: 用户在支付完成后可以申请退款，需要支持全额退款和部分退款，退款需要经过客服审核。

**核心业务对象**: 订单(Order)、退款单(Refund)、支付记录(Payment)
**核心流程**: 用户申请退款 → 客服审核 → 退款执行
**涉及角色**: 用户、客服
