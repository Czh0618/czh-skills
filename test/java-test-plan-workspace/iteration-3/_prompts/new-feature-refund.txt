新需求：订单支持部分退款。规则：只有已支付且未发货的订单可以退款；单次退款金额不能超过订单实付金额，多次部分退款累计也不能超过；退款成功后回补库存并回写订单状态（需求里没写退款后订单状态具体用哪个值）；同一个退款请求重复提交只能生效一次。接口契约已确认：POST /api/orders/{id}/refunds。项目是 Java 17 / Spring Boot 3 / MyBatis，pom.xml 里有 spring-boot-starter-test（含 JUnit 5、Mockito），没有 jqwik、Testcontainers、RestAssured；数据库是 MySQL，迁移脚本用 Flyway 管理，本机和 CI 能跑 Docker，dev、test 各环境另有自己的 k8s。已确认的业务口径：部分退款和退满靠订单状态区分，退满用“已退款”；“同一个退款请求”按订单加金额判断，重复提交报错；部分退款不补库存，退满整单回补；退款走第三方渠道异步回调，渠道失败记录为退款失败；已支付未发货由另一个字段记录，部分退款后还可以继续退款。需求方说大促前要上线，越快越好。先别写实现，帮我把测试这块理清楚。
