# 防御性需求清单 — 优惠券系统

> 原始需求：我们要做一个优惠券系统，支持满减券、折扣券、新人券。用户下单时可以选择使用优惠券，系统需要校验优惠券的使用条件。

> 核心业务对象：优惠券（满减券、折扣券、新人券）、订单、用户
> 核心流程：用户下单 → 选择优惠券 → 系统校验使用条件 → 抵扣金额 → 完成支付
> 涉及角色：用户、运营人员（券的创建/发放）、系统（自动校验）
